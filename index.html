How this works

Every Monday a GitHub Action downloads all planets with 1.6 ≤ R ≤ 4 R⊕ from the NASA Exoplanet Archive and searches arXiv (astro-ph.EP) for new JWST papers that name those planets. Hand-reviewed results (instruments, composition, source) come from data/jwst_results.json. A planet flagged New paper was found automatically and has not been reviewed yet; its composition is not summarized until someone adds it to that file.

JWST observations (MAST): each week the script also searches the MAST archive for JWST science observations whose target name matches a planet or its host star. This includes data that is still proprietary and unpublished, shown with its release date. Wavelengths come from the archive's recorded coverage (a “~” marks nominal values for that instrument mode). “Host-level match” means the proposer named the star, not the planet, so the data may be for a different planet in the same system. Only observations that have already been executed appear: approved programs that are scheduled but not yet observed are not listed, and a target filed under an unusual name can be missed.

“No published result in tracker” only means this tracker has no reviewed paper for that planet. Some curated masses and temperatures are rounded; verify against the cited source before relying on a row.
