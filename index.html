How updates work & data sources

This is a static snapshot: the page cannot fetch new papers by itself. Each week the table is refreshed by re-running a literature search (arXiv astro-ph.EP, ADS, MAST) and republishing with new rows. Rows are a curated set of sub-Neptunes with published JWST results; many more have approved JWST programs but no paper yet, so absence here does not mean “not observed”.

For the full detected population (1,000+ planets), download a CSV from the NASA Exoplanet Archive with columns pl_name, hostname, pl_rade, pl_bmasse, pl_orbper, pl_eqt and use “Import” above; planets with 1.6 ≤ R ≤ 4 R⊕ are added and matched to JWST results by name. JWST proposals: MAST. Values are rounded and some are from my recollection of the papers; verify against the cited source before use. Only what the papers report is listed; “debated” marks results with competing interpretations.
